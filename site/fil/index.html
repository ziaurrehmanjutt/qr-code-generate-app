Mga tampok

Ang DiyaQR ay mabilis at magandang QR code creator at scanner. Gumawa ng QR code para sa link, Wi-Fi, contact, event, o lokasyon, i-istilo ayon sa gusto mo, at i-save o ibahagi sa loob ng ilang segundo. Mag-scan ng anumang QR code o barcode gamit ang camera o mula sa larawan, at kumilos agad sa isang tap.

✨

Gumawa ng anumang QR code

  • Teksto, link, email, telepono, SMS, WhatsApp, Wi-Fi, contact card, event sa kalendaryo, at lokasyon sa mapa
  • Live preview habang nagta-type
  • Gamitin ang kasalukuyan mong lokasyon para sa mga map code
🎨

Gawin mong iyong-iyo

  • Mga handang istilo ng kulay, pati linear at radial na gradient
  • Piliin ang hugis ng mga tuldok, frame ng sulok, at tuldok ng sulok
  • Magdagdag ng sarili mong logo mula sa gallery o link ng larawan
  • Simpleng antas ng error correction na may malinaw na paliwanag, at babala kapag mahirap i-scan ang disenyo
📷

Mag-scan at kumilos agad

  • Mag-scan gamit ang camera o pumili ng larawan mula sa gallery
  • Mga smart action: buksan ang website, tumawag, magpadala ng SMS o email, buksan sa Maps, idagdag sa kalendaryo, i-save ang contact, o kumonekta sa Wi-Fi
  • Mga paalala sa seguridad para sa pinaikling link, hindi naka-encrypt na http link, at link na nakaturo sa IP address
💾

I-save, ibahagi, i-edit

  • I-export bilang PNG, JPEG, SVG, o WebP
  • I-save sa gallery, ibahagi sa anumang app, o itago ang code sa app at i-edit mamaya
  • Kasaysayan ng scan, mga paborito, at paghahanap
